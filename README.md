# PD Schedule Manager

구글 시트 로드맵(연도 → 월 → 담당자 줄 → 피쳐 카드) 형태의 일정 관리 웹 앱입니다.
피쳐 카드를 끌어서 다른 달이나 다른 담당자로 옮길 수 있고, 구글 시트와 동기화할 수 있습니다.

## 로드맵 탭 (보드)

시트 하나 안의 부서별 로드맵 탭 7개를 화면 위쪽 탭으로 전환하며 봅니다.
캐릭터 컨셉 · 캐릭터 3D · 배경 컨셉 · 배경 3D · 리깅 · 월드애니 · FX

- 탭마다 연도 줄 위치, 연도 사이 빈 열, 마일 스톤/이슈 정리 같은 헤더 줄 수가 달라도 **자동으로 인식**합니다.
- 탭마다 데이터 파일(`data/boards/<id>.db`)과 동기화가 따로라서 한 탭의 변경이 다른 탭에 영향을 주지 않습니다.
- "시트 동기화" 스위치는 7개 탭을 한꺼번에 켜고 끕니다. 구글 호출이 몰리지 않게 탭마다 시차를 두고 동기화합니다.
- 현황판 탭([PC] [NPC] [BOSS] [MOB] [WP] [ENV])과 세부일정/외주일정 탭은 아직 연결하지 않았습니다.

## 실행

Node.js 22.13 이상이 필요합니다. (추가 패키지 설치 없음)

```bash
cp .env.example .env      # 값을 채웁니다 (아래 참고)
npm start                 # http://localhost:3000
npm test                  # 테스트
```

## 로그인과 비밀번호

1. `.env`의 `ADMIN_USERNAME`에 사용할 아이디(회사 이메일)를 넣고 `ADMIN_PASSWORD`는 **비워 둡니다**.
2. 서버를 처음 시작하면 그 아이디로 관리자 계정이 만들어지고, **첫 비밀번호는 아이디와 같습니다.**
3. 처음 로그인하면 비밀번호 설정 창이 뜨고, 새 비밀번호(8자 이상, 아이디와 다르게)를 정하기 전에는 서버가 다른 기능을 막습니다.
4. 이후에는 상단의 "비밀번호 변경"으로 언제든 바꿀 수 있습니다.

계정은 직접 만든 것만 존재하며 회원가입 기능은 없습니다.
계정을 추가하거나 비밀번호를 초기화하려면:

```bash
npm run create-user -- <아이디> admin            # 첫 비밀번호 = 아이디, 로그인 후 변경 필요
npm run create-user -- <아이디> viewer <비밀번호>  # 조회 전용 계정
```

## 구글 계정 연동

화면 상단 **구글 시트 연동**에서 시트 주소를 저장하고 **구글 계정 연동 신청**을 누르면 구글 동의 화면으로 이동합니다.
승인하면 이 앱이 그 계정의 권한으로 시트를 읽고 쓰며, 이후 **시트 동기화** 스위치를 켤 수 있습니다.

처음 한 번, 구글 쪽 준비가 필요합니다.

1. [Google Cloud Console](https://console.cloud.google.com/apis/credentials)에서 프로젝트를 만들고 **Google Sheets API**를 사용 설정합니다.
2. **OAuth 동의 화면**을 설정합니다. 회사 Workspace 계정만 쓴다면 사용자 유형 **내부**를 고릅니다.
3. **OAuth 클라이언트 ID(웹 애플리케이션)**를 만들고 승인된 리디렉션 URI에 `http://localhost:3000/api/google/callback`을 넣습니다.
   (`PUBLIC_URL`을 바꿨다면 `${PUBLIC_URL}/api/google/callback`)
4. 발급된 값을 `.env`의 `GOOGLE_OAUTH_CLIENT_ID`, `GOOGLE_OAUTH_CLIENT_SECRET`에 넣고 서버를 다시 시작합니다.
5. 브라우저에서는 `PUBLIC_URL`과 같은 주소(기본 `http://localhost:3000`)로 접속해야 합니다.

연동 정보(갱신 토큰)는 `data/roadmap.db`(계정과 함께 보관)에 암호화되어 저장되므로 `data/` 폴더는 외부에 공유하지 마세요.
연동이 끊기면(비밀번호 변경, 구글 계정의 앱 권한 제거 등) 화면에 "연동이 끊겼어요"가 표시되고, 다시 연동 신청을 하면 됩니다.

## 시트 데이터 가져오기

시트를 CSV로 내보낸 파일에서 로드맵 7개 탭을 처음 채울 수 있습니다.

```bash
npm run import -- <CSV 파일>              # 7개 탭 모두
npm run import -- <CSV 파일> "FX 로드맵"  # 한 탭만
```

예전(탭 하나) 버전의 `data/roadmap.db`에 로드맵 내용이 있으면, 서버를 시작할 때 첫 번째 탭(캐릭터 컨셉)으로 자동 이전됩니다.

구글 계정 연동 후 동기화를 켜면 시트에서 직접 가져옵니다.

## 알려진 한계

- 시트에서 여러 달에 걸쳐 병합된 칸은 한 달짜리 카드로 가져옵니다.
- 시트에 칠해진 칸 색은 반영하지 않고, 카드 색은 `[MOB]`, `[PC]` 같은 태그 기준입니다.
