구글 시트 연동

처음 한 번 필요한 설정 (구글 OAuth 클라이언트)
  1. Google Cloud Console에서 프로젝트를 만들고 Google Sheets API를 사용 설정합니다.
  2. OAuth 동의 화면을 설정합니다. 회사 구글 계정(Workspace)만 쓴다면 사용자 유형을 내부로 고르면 됩니다.
  3. 사용자 인증 정보 → OAuth 클라이언트 ID → 웹 애플리케이션을 만들고, 승인된 리디렉션 URI에 아래 주소를 그대로 넣습니다.
  4. 발급된 클라이언트 ID와 보안 비밀번호를 서버의 .env 파일에 GOOGLE_OAUTH_CLIENT_ID, GOOGLE_OAUTH_CLIENT_SECRET으로 넣고 서버를 다시 시작합니다.
  5. 이 앱은 위 주소와 같은 주소()로 접속해야 연동이 완료됩니다.
